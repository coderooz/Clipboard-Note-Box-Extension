# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Clipboard & Note Box seriously. If you discover a security vulnerability, please follow these steps:

### Do Not

- Open a public GitHub issue for security vulnerabilities
- Share the vulnerability details publicly until it has been addressed

### Do

1. **Contact us directly** at [contact@coderooz.in](mailto:contact@coderooz.in) with the subject line `[SECURITY] Clipboard & Note Box - Vulnerability Report`
2. **Use our contact form** at [https://coderooz.in/contact](https://coderooz.in/contact?subject=[SECURITY]%20Vulnerability%20Report&message=Please%20describe%20the%20vulnerability)
3. Include as much detail as possible:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

## Response Timeline

- **Acknowledgment**: Within 48 hours of receiving your report
- **Assessment**: Within 5 business days
- **Fix deployment**: Within 14 days for critical issues
- **Public disclosure**: After a fix is available and users have had time to update

## Security Best Practices for Contributors

- Never commit secrets, API keys, or credentials
- Review all dependencies for known vulnerabilities
- Keep the extension permissions minimal and justified
- Sanitize all user input before processing
- Use HTTPS for any external communication

## Scope

This security policy covers:

- The Chrome extension source code
- GitHub repository and workflows
- Published releases and distribution

## Credits

We appreciate responsible disclosure and will credit security researchers who report valid vulnerabilities (unless they prefer to remain anonymous).
